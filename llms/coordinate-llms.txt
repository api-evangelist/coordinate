# Coordinate

> Coordinate (CoordinateHQ) is a client project-execution platform and branded client portal for client-facing businesses. Its REST API adds, updates, and retrieves projects, project pages, tasks, task groups, stakeholders, goals, progress reports, comments, and organizations, and a webhook API streams create/update events. All requests are scoped by an API key to a single vendor.

## API
- [Coordinate REST API reference (HTML)](https://app.coordinatehq.com/static/API_Documentation.html): Authoritative endpoint reference.
- [Coordinate REST API reference (Markdown)](https://app.coordinatehq.com/static/API_Documentation.md): Agent-oriented Markdown version of the reference.
- Base URL: https://app.coordinatehq.com/api/v1
- Authentication: API key in a custom `Bearer:` header (Settings > Integrations > API Keys).
